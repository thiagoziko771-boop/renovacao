Termos de Renovação de CNH

Antes de prosseguir, leia e aceite os seguintes termos:

  • Declaro que as informações fornecidas são verdadeiras.
  • Autorizo a análise de dados para verificação de elegibilidade no sistema do DETRAN.
  • Estou ciente de que a renovação está sujeita à análise e aprovação dos órgãos competentes.
  • Compreendo que o pagamento da taxa de renovação é obrigatório para conclusão do processo.
  • Autorizo o uso dos meus dados pessoais conforme a Lei Geral de Proteção de Dados (LGPD).
Serviço oficial do Governo Federal: Este é um serviço oficial e seguro. Seus dados são protegidos pela Lei Geral de Proteção de Dados (LGPD).
